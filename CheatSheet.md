# BBCode Basics & Advanced Cheat Sheet

### Text Formatting
* **Bold Text:** `[b]Bold Text[/b]`
* **Italic Text:** `[i]Italic Text[/i]`
* **Underlined Text:** `[u]Underlined Text[/u]`
* **Strikethrough Text:** `[s]Strikethrough[/s]`

### Links and Images
* **Standard URL:** `[url]https://example.com[/url]`
* **Named URL:** `[url=https://example.com]Click Here[/url]`
* **Image:** `[img]https://example.com[/img]`
* **Resized Image:** `[img=200x100]https://example.com[/img]` *(Width x Height)*

### Alignment and Layout
* **Center Text:** `[center]Centered Text[/center]`
* **Left Align:** `[left]Left-aligned text[/left]`
* **Right Align:** `[right]Right-aligned text[/right]`
* **Quote Box:** `[quote]This is a quoted message.[/quote]`
* **Attributed Quote:** `[quote=Author]This is what they said.[/quote]`
* **Code Block:** `[code]Preformatted monospace text[/code]`

### Size and Color
* **Font Color:** `[color=red]Red Text[/color]` or `[color=#FF0000]Hex Red[/color]`
* **Font Size:** `[size=4]Larger Text[/size]` *(Note: Some forums use percentages like `[size=150%]`)*
* **Font Face:** `[font=Courier]Monospace Font[/font]`

### Lists
* **Bullet List:**
  ```text
  [list]
  [*]First item
  [*]Second item
  [/list]
  ```
* **Numbered List:**
  ```text
  [list=1]
  [*]Step one
  [*]Step two
  [/list]
  ```

### Advanced Features
* **Spoiler Box:** `[spoiler]Hidden text here[/spoiler]`
* **Named Spoiler:** `[spoiler=Button Text]Hidden text here[/spoiler]`
* **Inline Spoiler:** `[ispoiler]Blurs or hides inline text[/ispoiler]`
* **Tables:** 
  ```text
  [table]
  [tr]
  [th]Header 1[/th]
  [th]Header 2[/th]
  [/tr]
  [tr]
  [td]Cell 1[/td]
  [td]Cell 2[/td]
  [/tr]
  [/table]
  ```
